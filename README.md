# 포탄대작전 💣

링크 하나로 친구와 붙는 턴제 탱크 포격전. 가입·설치·서버 비용·API 키 없음.

- 주소: https://cheon-jaeryong.github.io/potan/
- 방 만들기 → 초대 링크(`?r=방코드`)를 카톡으로 보내면 어디서든 접속 (최대 8명, 컴퓨터 추가 가능)
- 혼자일 땐 “컴퓨터와 연습하기” (인터넷 연결 없이 브라우저 안에서만)

## 게임 규칙
- 내 닉네임이 곧 탱크 이름 — 탱크 위 이름표로 표시
- 턴마다 이동(게이지만큼) → 각도(↑↓, 휴대폰은 각도 막대를 위아래로 밀기 · 화면을 위아래로 쓸기) → 스페이스(발사 버튼)를 꾹 눌러 파워 모으고 떼면 발사
- **예상 경로**: 내 차례엔 포탄이 **꼭대기(꺾이는 곳)까지만** 점선으로 보임 — 떨어지는 곳은 감으로!
- **점프**(J / 점프 버튼): 한 턴에 한 번, 이동 게이지 30 — 구덩이·섬 사이·건물 건너기
- 바람(-10~10)이 턴마다 바뀜, 지형은 폭발로 뻥 뚫리고(구멍 너머로 하늘이 보임), 떨어져도 낙하 피해는 없음 — 물에 빠지면 탈락
- 무기 3개: 1·2번 일반, 3번 필살기(턴마다 +25, 맞은 피해만큼 게이지 충전 → 100%면 사용)
- 아이템(한 판에 1개씩, 한 턴에 하나): 회복 +30 · 2연발 · 강화탄(피해 1.4배) · 무풍
- 오래 끌면(인원×8턴 이후) 물이 차오름
- 개인전 / 팀전(레드·블루), 턴 시간 20·30·45초

## 코인 · 상점 · 강화 (v1.2, 지금은 테스트 단계)
- 판이 끝나면 코인: 참가 30 + 입힌 피해×0.8 + K.O.×40 + 승리 120 (+2등 20). 처음 500코인
- 상점에서 탱크 사기, 탱크마다 강화 4가지(공격력 +4% · 체력 +6 · 이동 +16 · 필살 충전 +3, 각 5단계 / 150·300·500·800·1200코인)
- 강화는 온라인 대전에서도 적용(게임 시작 정보에 각자 강화 단계가 들어감)
- 탱크를 고르면 **자세히보기** 창(능력치·무기 설명) — "하루 동안 끄기" 가능, 카드의 ⓘ로는 언제든 보기
- 지금은 이 브라우저에만 저장(서버·보안 없음), 상점 아래 🧪 테스트 코인 버튼 있음(`shop.js`의 `TEST_MODE`)

## 구조 (정적 파일만)
- `engine.js` 지형(픽셀 마스크)·물리·무기·컴퓨터 AI — 1/120초 고정 간격, 내부 난수 없음 → 같은 입력이면 모든 기기에서 같은 결과
- `draw.js` 탱크·배경·폭발·미니맵을 캔버스로 직접 그림(이미지 파일 없음)
- `app.js` 화면·대기실·통신·턴 진행·조작·소리(WebAudio 합성)
- `shop.js` 코인 지갑 · 상점 · 강화 · 탱크 자세히보기 창
- `vendor/mqtt.min.js` MQTT 5.16.1 자체 보관

## 통신
공개 MQTT 중계 2곳에 **동시 접속**(broker.emqx.io:8084, public.cloud.shiftr.io:443), 토픽 `potan-battle/v1/<방코드>/m` 하나에 JSON 메시지.

- 쏜 사람이 화면 없이 한 발을 끝까지 계산해 결과(탱크 상태·구멍 목록)를 입력과 함께 보냄 → 모두 같은 계산으로 애니메이션을 보여 주고 끝나면 결과로 맞춤(지형이 다르면 구멍 목록으로 다시 그림)
- 방장: 대기실 관리, 컴퓨터 차례 계산, 자리 비운 사람 턴 넘기기, 2.5초마다 상태 확인값 → 어긋난 사람은 자동 재동기화
- 방장이 나가면 가장 먼저 들어온 사람이 이어받음, 새로고침하면 같은 자리로 자동 재입장(방장이 새로고침해도 남은 사람이 판을 돌려줌)
- 같은 브라우저 탭 두 개도 서로 다른 사람으로 들어감(탭별 아이디)
